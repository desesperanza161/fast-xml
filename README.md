руководство пользователя

Привет!Рады что ты решил попробовать наше приложение.Поверь оно тебя не разочарует. Всё очень просто: рисуешь на холсте, добавляешь текст и картинки, а потом сохраняешь результат как шаблон или экспортируешь в картинку/PDF. Давай разберёмся,как управлять этим приложением

Главный экран

Когда ты открываешь редактор, видишь три основные зоны:

Панель свойств - слева от рабочей области. Она появляется, только когда ты выберешь какой-нибудь объект (надпись или картинку). Тут можно менять шрифт, размер букв, цвет, делать текст жирным или курсивом, а для картинок — прозрачность. Белый холст - находится во главе всего. На нём ты размещаешь текст и изображения. Можешь перетаскивать, редактировать, удалять и заменять. Главная панель инструментов - справа от рабочей области. Здесь кнопки для добавления текста, загрузки картинок, выбора размера страницы (A4;A5;Письмо или собственные размеры), а также блоки: “Шаблон” и “Экспорт”

Кнопочки

Добавить текст — на холсте появится поле «Введите текст». Можешь сразу печатать. Загрузить изображение — откроется окно выбора файла. Выбери картинку на компьютере, и она появится на холсте. Удалить объект — удалит выделенную надпись или картинку (также работает клавиша Delete на клавиатуре).

Выбор темы Можно переключить между “Светлой”” и “Тёмной”. В тёмной все панели станут серыми, глаза меньше устают.

Шаблоны “Выпадающий список” — здесь будут названия всех твоих сохранённых шаблонов. Когда ты сохраняешь свой макет, он появляется в этом списке. Выбираешь название — и холст сразу превращается в тот самый макет. “Сохранить как шаблон” — нажимай, когда хочешь запомнить текущий шаблон. Введи понятное имя (например «Отчет за март»), и она отправится в базу данных. В следующий раз ты сможешь её снова открыть. “Мой шаблон” — эта кнопка появляется, если у тебя уже есть хотя бы один сохраненный шаблон. Она загружает последний сохраненный шаблон.

Страница

Выбери нужный формат: из уже представленных: А4,А5,Письмо или задай собственные размеры и холст подстроится под выбранный размер.
Экспорт — сохранить результат

Под блоком с размерами есть компонент “Экспорт”. Здесь ты можешь “скачать готовую работу” на компьютер: -PNG/JPEG -PDF -SVG -XML
Новый проект “Новый проект” — очищает холст, сбрасывает цвет фона на белый и устанавливает размер по умолчанию. Внимание: все несохранённые изменения пропадут! Поэтому сначала сохрани шаблон.

Цвет фона Квадратик с выбором цвета — щёлкни, и весь холст зальётся выбранным цветом. Можно сделать фон не белым, а, например, нежно-голубым.

Панель свойств

Когда ты выделяешь текстовую надпись на холсте слева появляются настройки: Текст - большое поле, в котором можно редактировать содержимое. Шрифт - выбери из списка (Arial, Times New Roman, Courier New, Verdana). Размер - высота букв. Цвет - сам цвет текста (палитра). Жирный\Курсив\Подчёркнутый - кнопки для стиля. Выравнивание - по левому краю, по центру, по правому краю.

Если выделить картинку, появится поле - прозрачность. Можно сделать изображение полупрозрачным, чтобы текст накладывался поверх.

Благодарим за доверие к нам, оставайся с нами и следи за новым функционалом.





# frontend

This template should help get you started developing with Vue 3 in Vite.

## Recommended IDE Setup

[VS Code](https://code.visualstudio.com/) + [Vue (Official)](https://marketplace.visualstudio.com/items?itemName=Vue.volar) (and disable Vetur).

## Recommended Browser Setup

- Chromium-based browsers (Chrome, Edge, Brave, etc.):
  - [Vue.js devtools](https://chromewebstore.google.com/detail/vuejs-devtools/nhdogjmejiglipccpnnnanhbledajbpd)
  - [Turn on Custom Object Formatter in Chrome DevTools](http://bit.ly/object-formatters)
- Firefox:
  - [Vue.js devtools](https://addons.mozilla.org/en-US/firefox/addon/vue-js-devtools/)
  - [Turn on Custom Object Formatter in Firefox DevTools](https://fxdx.dev/firefox-devtools-custom-object-formatters/)

## Type Support for `.vue` Imports in TS

TypeScript cannot handle type information for `.vue` imports by default, so we replace the `tsc` CLI with `vue-tsc` for type checking. In editors, we need [Volar](https://marketplace.visualstudio.com/items?itemName=Vue.volar) to make the TypeScript language service aware of `.vue` types.

## Customize configuration

See [Vite Configuration Reference](https://vite.dev/config/).
